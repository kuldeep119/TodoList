# 🏔️ Peak

**Peak** is a sleek, minimalist To-Do application built to help you organize your daily tasks and reach the "peak" of your productivity. Developed natively for iOS using Swift and SwiftUI.

---

## 📱 Features

* **Task Management:** Quick and easy creation, tracking, and deletion of tasks.
* **Modern UI:** A clean, gesture-driven interface designed with SwiftUI.
* **Stay Organized:** Record "Things" as they come to mind so you never lose focus.
* **Native Performance:** Optimized for a smooth and responsive experience on iOS.

## 🛠️ Tech Stack

* **Language:** Swift 5.9+
* **Framework:** SwiftUI
* **Platform:** iOS 17.0+
* **Architecture:** MVVM (Model-View-ViewModel)

## 🚀 Getting Started

### Prerequisites
* A Mac running **macOS Sonoma** (or later).
* **Xcode 15.0** or higher installed.

### Installation
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/kuldeep119/Peak.git](https://github.com/kuldeep119/Peak.git)
    ```
2.  **Open the project:**
    Navigate to the project directory and open `Peak.xcodeproj`.
    ```bash
    cd Peak
    open Peak.xcodeproj
    ```
3.  **Run the App:**
    Select your preferred iOS Simulator or a physical device and press `Cmd + R`.

## 📂 Project Structure
* `Peak/`: Contains the main SwiftUI Views, ViewModels, and Data Models.
* `Peak.xcodeproj`: The Xcode project configuration.
